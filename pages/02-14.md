## Case 14. The viral claim that an AI agent deleted an entire Swedish TV season rests on a single out

**Edition date** — 2026-10-15

Bottom line: The viral claim that an AI agent deleted an entire Swedish TV season rests on a single outlet's unnamed sources; the broadcaster denies an independent AI agent was responsible and points to a failed backup system.**
· On 2026-10-14, Swedish daily **Aftonbladet** reported, citing unnamed sources, that an AI agent given server access by production company **Mastiff** deleted the finished edit of *The Challenge Sverige*. Broadcaster **TV4** confirmed only a "technical breakdown."
· TV4 program chief **Mia Lindqvist** told Sveriges Radio no independent AI agent deleted the material, attributing the loss to Mastiff's malfunctioning **backup system** ("human factor," "not AI"). Mastiff's CEO declined to comment.
· **No technical logs or incident report** have been published; only the **finished edit** was lost — the **raw footage still exists**, and the premiere moved from 2022-11-22 to 2027.
Sources: Aftonbladet / TV4 / Omni (Sveriges Radio) / TechRadar / Futurism / news9live
